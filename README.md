# Montgomery Fleet Equipment Inventory Data Analysis

## 📌 Project Overview
In this project, I acted as a Junior Data Analyst in a local government office. The objective was to clean, prepare, and analyze fleet inventory data to prepare it for visualization and reporting. The project is divided into two main phases: Data Cleaning and Data Analysis using Pivot Tables.

## 🛠️ Tools Used
* **Microsoft Excel** (Data Cleaning, Formulas, Pivot Tables)

## 📂 Phase 1: Data Cleaning & Preparation (PART 1)
In this phase, I transformed the raw CSV data into a clean, structured XLSX format. Key tasks performed:
* **File Conversion & Formatting:** Converted CSV to XLSX and adjusted column widths for better readability.
* **Removing Blank Rows & Duplicates:** Utilized the `Filter` feature to eliminate empty rows and applied `Remove Duplicates` / `Conditional Formatting` to ensure data uniqueness.
* **Data Quality Checks:** Fixed spelling errors across the dataset and used `Find and Replace` to remove unnecessary double spaces (whitespace).
* **Data Manipulation:** Used the **Flash Fill** feature to merge and correct split Department names into a single column, subsequently removing redundant columns.

## 📊 Phase 2: Data Analysis & Pivot Tables (PART 2)
In the second phase, I analyzed the cleaned data using various Excel functions and Pivot Tables to extract meaningful insights. Key tasks performed:
* **Table Formatting & Descriptive Statistics:** Formatted the data as a formal Excel Table. Utilized `AutoSum` to calculate key metrics for the Equipment Count (SUM, AVERAGE, MIN, MAX, COUNT).
* **Pivot Table 1 (Summary):** Created a Pivot Table displaying the sum of equipment count by `Department`, sorted in descending order to easily identify departments with the largest fleets.
* **Pivot Table 2 (Department Deep-Dive):** Built a hierarchical Pivot Table categorizing `Equipment Class` under each `Department`. Collapsed the data to focus specifically on the "Transportation" department.
* **Pivot Table 3 (Equipment Class Deep-Dive):** Restructured the Pivot Table to show `Department` underneath `Equipment Class`, collapsing the view to focus primarily on the "CUV" (Crossover Utility Vehicle) category.

## 💡 Conclusion
This project demonstrates proficiency in essential Excel data analyst skills, including data cleaning, data integrity verification, formatting, and the advanced use of Pivot Tables to summarize and analyze hierarchical categorical data.
