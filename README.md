# Montgomery Fleet Equipment Inventory Data Analysis

## 📌 Project Overview
In this project, I acted as a Junior Data Analyst to clean, prepare, and analyze fleet inventory data. This showcase visualizes the transformation of raw data into actionable insights using Excel.

## 🛠️ Tools Used
* **Microsoft Excel / Google Sheets** (Data Cleaning, Formulas, Pivot Tables)

## 📂 Phase 1: Data Cleaning & Preparation (PART 1)
In this phase, I transformed raw CSV data into a clean, structured XLSX format, ensuring data integrity.

### 🔄 The Transformation (Before & After)

| Before Cleaning (Messy Data) | After Cleaning (Structured & Merged Departments) |
| --- | --- |

*Key tasks performed:* Converted CSV to XLSX, adjusted column widths, used **Filters** to remove blanks, applied **Remove Duplicates**, fixed spelling, and used **Flash Fill** to fix and merge split Department names into a single column.
